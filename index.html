ESTREGG

[ v1.1.8 - Update Released ]
A Terminal Space Simulation Odyssey by YB_Jeorgie

About the Game

estregg is an open-source terminal ASCII game designed for Python Curses console environments. Pilot your rocket through 100 generated starfields, track down uncharted planets, navigate black holes, deploy secret command sequences, and inspect celestial star masses across Linux, macOS, Windows, and Termux environments.

Features & v1.1.8 Core Updates

  • 100 Planetary Levels: Traverse through 100 unique star systems complete with dynamic warp portals and victory sequences.
  • Secret Terminal Engine (Ctrl + E): In-game secret command prompt supporting cheat parameters, warp calls, and dev commands.
  • Star Scanner Integration (R): Real-time stellar mass, solar radius, and star classification telemetry panel overlay.
  • ASCII Art & Banner Alignment: Refactored title text rendering routines across custom terminal font engines.
  • Orbital & Black Hole Physics: Dynamic gravity loops, wormholes, and black hole event horizons built into the Python Curses game core.
  • Saved Progress & Telemetry (V / P / Ctrl + S): In-game progress saving, settings configuration, and quick-save state handlers.

How to Install & Run

Ensure you have pipx set up on your machine, then install and launch directly from your terminal:

pipx install estregg-ybj
estregg

To upgrade an existing installation to v1.+.+ Run:

pipx upgrade estregg-ybj
