ESTREGG

A Terminal Space Simulation Odyssey by corruption123ter-ux

About the Game

estregg is a specialized ASCII terminal game designed for console environments. Pilot your rocket through generated starfields, track down uncharted planets, manipulate space physics engine portals, and interface hardware controllers directly using EVDEV pipelines.

Features

  • Dynamic Galaxy Sectors: Procedurally generated starfields and multi-classification star data engine profiles.
  • Orbital Mechanics: Active pull and push physics loops powered by Sagittarius A* Black Hole and Polaris Emitters.
  • Hybrid Control Layout: Fully maps inputs across standard PC Keyboard loops and native Gamepad controllers via USB/Virtual nodes.
  • Retro Animation Engines: Complex terminal wrapper routines including wormhole transit event triggers.

How to Install & Run

Ensure you have Python 3 and its developmental components installed on Linux or macOS. Run the application directly from your shell layout:

git clone https://github.com.git
cd estregg
python3 estregg.py
